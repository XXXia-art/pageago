# PageAgo

一个本地优先的浏览器时间记录工具：浏览器扩展采集前台网页活动，网页时间线用于查看、回顾和导出。无需账号、服务器、模型 API 或额外安装依赖。

这是 PageAgo 的浏览器活动记录器，根目录保留旧版历史访问时间线工具。

## 先看效果

双击 `Open-PageAgo.cmd`，或打开 `dist/index.html`。独立 HTML 可离线运行，默认展示合成示例。

预览可操作日期、活动详情、时间轴缩放、导入和导出。普通网页没有权限监控浏览器的其他标签页；**真实记录通过配套扩展完成**。

## 在 Edge / Chrome 开始记录

1. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
2. 开启开发人员模式，点击“加载解压缩的扩展”，选择本项目的 `extension` 文件夹。也可解压 `output/pageago-extension.zip` 后选择解压目录。
3. 将 PageAgo 固定到工具栏，点击图标打开时间线，再点日期按钮 → 设置 → 开始记录。默认关闭，安装不会自动开始采集。

扩展页面即实际使用的网站，不需要访问一个在线服务。重新打开浏览器会保留开始/暂停状态；可在日期菜单的设置中暂停。无痕窗口不采集。

## 界面与操作

首页是纯色米白画布（`#EFE8DC`）与一条居中的合并时间轴，没有侧栏、统计卡片或额外列表。真实记录模式不展示示例色块。

- 左下角的日期胶囊直接显示所选月份和日期，左右圆按钮切换前后一天；点击胶囊打开日历，可选任意过去日期或回到今天。同月切换只翻转中间的日期键，跨月或跨年时三块键同步翻转。三块按键独立放置，不带椭圆底座；月份与日期使用相同的 18px 字体和字重。键帽由本地 Three.js 绘制，实体侧面与文字一起转动，按压时略微下沉；连续反向切换保留当前角度和速度，减少动态效果时直接更新。浏览器没有 WebGL 或丢失绘图上下文时保留可用的静态日期按钮。日历支持方向键、Page Up / Down、Home / End 移动焦点，Enter 选择，Escape 关闭。
- 切到前一天时，当前网页标签、垂直连线和活动色块一起向右淡出，前一天的记录从左侧进入；下一天方向相反。时间标尺与日期控件保持原位。过渡约 420 毫秒，日期和真实数据立即切换；连续点击会从当前画面重新接续，不排队。减少动态效果、切到后台、调整窗口或直接操作时间轴时立即结束过渡。
- 点击网页标签或 `+N` 列表条目时，会保持高亮同一网站当天所有网页的标签、连线和活动色块，并打开所点网页的详情；其他网站稍微淡化。例如点击 B 站任意页面，会同时突出视频页、个人空间和直播页。分组沿用网站配色使用的可注册域名规则，独立托管站点仍分别识别；每个 URL、访问区间与时长保持独立。悬停或仅键盘聚焦只显示网页提示，Enter / Space 与点击一致。再次点击同一网页、点击空白处、关闭详情或按 Esc 取消；点击其他网页切换详情和对应网站。缩放、滑动和同日数据更新保留高亮，切换日期或导入数据清除选择。
- 合并状态下最多显示 8 层标签，先为网页图标预留位置，再用图标之间的空白显示标题。拥挤时先隐藏文字；放大时间轴后标题逐步变长。所有标签统一图标在左、标题在右，始终保持单行，过长的文字以省略号收尾，包括最细的 30 分钟视图。边缘标签会向画布内让出文字空间；垂直细线仍指向准确时间。悬停、聚焦或打开详情可查看完整标题。只有图标本身也放不下时才显示 `+N`，点击后用小列表查看当前视窗内未显示的网页，列表包含图标、标题和时间，点击条目可打开详情；不会延长或补齐真实活动区间。
- 点击上方标签直接查看网页详情，悬停可看完整标题、首次活动时间与累计时长。标签和色带根据可注册域名自动分配低饱和纯色，新网站无需添加名单。配色不再循环使用固定的 12 色：从可扩展候选色中优先选择与已分配颜色感知差异更大的颜色；新增网站不会重排已有网站颜色。同站的不同路径、参数和子域名共用颜色，标签与区间保持一致。域名规则同时识别 `co.uk` 等复合后缀、国际化域名，以及 `github.io` 等平台上的独立站点；IP 和单段主机名按完整主机名区分。网站很多时色彩仍可能接近，网页图标与标题继续辅助识别。已知网站名称只改善显示，不决定分组或配色。
- 鼠标移到主轴色块上，可以看到当地时刻、网站图标和单行短标题。移到空白处只显示时刻，移出时间轴后提示收起。刻度密度随缩放调整。
- 主轴与书房之间的 30 格刻度均分全天，每格 48 分钟。点一格跳到该格的起始时刻，拖动时主轴跟随所选分钟，实时显示附近一小时的网页，书房光线同步变化。已放大到更细的范围时沿用当前宽度。松手停在当前时刻，拖动中按 Esc 可回到原视图。点击刻度右侧的回正箭头可恢复全天视图，刻度归到 12:00。聚焦刻度带后，方向键微调一分钟，Shift + 方向键跳一小时，Home / End 到日界。
- 在时间轴上滚动滚轮，以鼠标所在时刻为中心缩放；触控板捏合也可缩放，最细可查看 30 分钟。放大后左右拖动或横向滚动浏览，拖动结束保留轻微惯性；触控板横滑、Shift + 滚轮也可平移。`− / +` 调整缩放，`1×` 恢复当前日期的完整范围。缩放只改变视图，不改变记录。
- 滑过刻度时播放本地合成的轻微拨轮声。首次点击或按键激活浏览器音频，停下、切到后台即停止；设置中的“刻度音效”可静音并记住偏好。不下载音频、不使用苹果原声素材。
- 点击网页标签或 `+N` 列表条目查看各次访问。点击一次访问时间后，可以用「上一页」「下一页」沿当天的时间顺序回看。连续访问同一网址时，间隔不足 5 分钟会一起跳过，间隔达到 5 分钟则停在重访处。换到不同网址也会停，包括同一网站的其他网页。详情仍可逐次定位，色块宽度对应实际记录时长。
- 「返回原视图」恢复首次定位前的时间范围和缩放。直接关闭详情或按 Esc，会停在当前时段。
- 点击右下角的放大镜或按 `/` 唤出浮动搜索栏。输入标题或域名即可查看当天的结果，也可以点地球图标先选网站。空栏按 ↓ 显示最近访问；用 ↑ / ↓ 选择网页，Enter 在新标签页打开，Esc 关闭。每个网址只列一次，点击右侧时间可定位到最近一次匹配的访问。
- 点击日期菜单中的「设置」可以暂停录制、导入或导出数据、查看计时说明和清空记录。清空仍须再次确认。
- 主轴可用 Tab 聚焦：`+ / −` 缩放，左右方向键平移，Home 恢复全天。没有下拉、展开箭头或小时详情视图。`+N` 列表支持上下键、Home / End 和 Enter；Escape 关闭列表或详情并还原焦点。

每天统一从本地时间 00:00 显示到 24:00，有无凌晨记录都保持完整日范围。仍可缩放、平移查看某个时段；点击 `1×` 或按 Home 恢复 00:00–24:00。所有时长对应当前日期，按区间并集计算。跨午夜的记录按本地日期裁切；重叠导入区间在合并轴上分层显示，不累加为更长使用时间。夏令时切换日按当地实际一天的长度计算位置和时长。

## 数据与隐私

- 记录当前网页 URL、标题、开始/结束时间；不读取正文、Cookie、密码、浏览器历史或表单。
- 仅在当前正常窗口获得焦点、标签页活跃且系统非空闲时记录 HTTP(S) 页面。扩展自身页面不计时。
- 不向外部发送浏览记录，不使用分析埋点，不通过远程服务查询网站图标。扩展通过 `favicon` 权限读取 Edge / Chrome 本机已缓存的网站图标；缓存缺失时使用离线打包图标或字母标识。普通离线 HTML 使用打包图标，支持子域名匹配。
- 网站配色映射保存在本机 `localStorage`，真实记录、示例和导入分别保存；清空 PageAgo 记录时也清除真实记录的配色映射。浏览器拒绝本地存储时退回当前页面内存，时间轴仍可使用。
- 真实数据保存在 `chrome.storage.local`，不会混入示例。导入文件只在当前页面内存中查看，不写入记录器；刷新后回到本机记录。
- 完整 URL 可能含查询参数等私人内容；导出文件也包含这些内容。URL 用户名/密码字段会被移除。
- 约 8 MiB 数据上限时暂停采集，不自动删除旧记录。卸载扩展会移除本机扩展数据，需要保留时先导出。

### 时间的含义

“前台活动”是**估计的浏览器前台时间，不是实际阅读或专注时长**。系统空闲阈值为 60 秒，阈值内的离开可能被计入；每约 30 秒保存一次，延迟超过 45 秒的时间不补算，崩溃可能丢失最后未保存的一段。没有用两次历史访问的跨度伪造停留时长。实现细节见 `extension/RECORDER.md`。

### 导入格式

```json
{
  "schema": "trace.v1",
  "source": "trace-recorder",
  "sessions": [
    {
      "id": "unique-session-id",
      "url": "https://example.com/page",
      "title": "网页标题",
      "host": "example.com",
      "start": "2026-11-08T01:00:00.000Z",
      "end": "2026-11-08T01:12:00.000Z"
    }
  ]
}
```

导入时根据 URL 重算 host，拒绝非 HTTP(S) 地址、重复 ID、无效或逆序时间。示例来源 `synthetic-demo` 在导出、重新导入后持续标记。旧版历史访问 JSON 不含可靠区间，不能当成此格式直接导入。

## 开发

需要 Python 3 和 Node.js（测试使用 Node 内置 WebSocket，建议 Node 22+）。不需要安装额外运行依赖；网页内已打包 [tldts](https://github.com/remusao/tldts) 7.4.19 及其域名后缀数据，以及 [Three.js](https://github.com/mrdoob/three.js/tree/r180) 0.180.0。域名识别与日期绘制全程离线，静止时不持续渲染日期键。固定版本、来源、校验值和 MIT 许可保存在 `vendor/`，构建只读取本地文件，不从 CDN 或网站查询用户域名。

从工作区根目录执行：

```powershell
python prototypes\trace-next\build.py
node --test prototypes\trace-next\tests\recorder.test.mjs
node prototypes\trace-next\tests\dashboard.test.mjs
node prototypes\trace-next\tests\overflow-list.test.mjs
node prototypes\trace-next\tests\date-highlight.test.mjs
node prototypes\trace-next\tests\date-timeline-motion.test.mjs
node prototypes\trace-next\tests\extension.test.mjs
```

构建产生离线页面、扩展目录与 ZIP。测试使用独立 Edge 临时配置、合成数据与 localhost 测试页面，不读取个人浏览器配置。实际前台采集测试依赖操作系统非空闲；空闲时会明确报告相关检查跳过。

额外的 `tests/hour-dial.test.mjs` 需要开发测试依赖 Playwright；品牌字标导出脚本需要 Pillow 与 fontTools，README 动图编码脚本需要 Pillow。这些依赖不参与网页运行或常规构建。

源文件：`index.template.html`、`dashboard.css`、`dashboard.js`、`date-control.js`、`date-control.css`、`date-capsule-three.js`、`date-timeline-motion.js`、`page-highlight.js`、`site-colors.js`、`build.py`、`extension/worker.js`、`extension/recorder-core.mjs`。

日期画面过渡由 `TraceDateTimelineMotion.create({scene, parts, reduced})` 管理。`change({fromDate,toDate}, apply)` 同步执行数据更新回调，再让 `#constellation` 和 `#lanes` 共用水平位移；`finish()` 清理动画，`snapshot()` 通过 `traceSnapshot().dateMotion` 提供当前方向、位移、透明度和离场层数量。前一天方向为 `1`，下一天为 `-1`。离场画面最多保留一个 `inert`、`aria-hidden` 的临时副本，位于数据场景外，移除 ID、数据标识和可聚焦控件，不参与记录查询、高亮或时长计算；结束后直接移除。

当前为可运行的本地首版；尚未发布到浏览器商店，也未部署到公网。当前重点为 PC 单窗口时间回顾，不包含跨设备同步、AI 推断、效率评分或后台音视频时长。

早期紧凑列表版本仅保留在本地归档中，不包含在公开发布内容里。
