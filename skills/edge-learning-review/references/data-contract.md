# 数据与分阶段执行

所有命令通过 `python "<skill-dir>/scripts/learning_review.py"` 调用；参数文件均为 UTF-8 JSON。

```text
collect [--copy-if-locked] [--user-data-dir PATH] [--output-dir PATH]
classify --input PATH [--assignments PATH] [--rules PATH] [--output-dir PATH]
aggregate --input output/learning_classified.json [--output-dir PATH]
review --input output/learning_summary.json [--output-dir PATH]
run [--input PATH] [--copy-if-locked] [--user-data-dir PATH]
    [--assignments PATH] [--rules PATH] [--output-dir PATH]
```

`run` 未指定 `--input` 时先采集；指定时直接分析已有文件。`classify`、`aggregate`、`review` 分别可独立重跑。部分配置文件失败时仍可生成部分报告，退出码保持 1；全部采集失败时不分析。

## collect

输入沿用 `edge_history_today.json`：`status`、带时区的 `start_time/end_time`、
`event_count`、`profiles`、`errors`、`visits`。每次访问包含
`profile,visit_id,url,title,visit_time`；同一配置文件内 visit_id 唯一，访问时间应在声明范围内。
URL、title 可为 null，以保留孤立访问。校验失败必须报错，不能静默跳过记录。

## classify

`learning_classified.json` 保留输入元数据和所有访问，为事件增加 `topic_id,topic_label,kind,
classification_reason,classification_source`。`kind` 为 `learning/other/unknown`。
规则匹配只提供可解释的候选分类，不代表实际学过或掌握相关内容。

Codex 可写一次性 assignments 覆盖部分事件，其余继续使用默认规则：

```json
{
  "assignments": [
    {
      "profile": "Default",
      "visit_id": 123,
      "topic_id": "vla-icl",
      "topic_label": "VLA 与上下文学习",
      "kind": "learning",
      "reason": "页面标题明确包含论文名；仅能确认访问，不能确认已读完"
    }
  ]
}
```

assignments 必须引用真实事件，不能重复引用；同一 topic_id 的标签与 kind 必须一致。
主题含义可由用户规则配置，不应将未知的视频/云文档强行判为学习或娱乐。

## aggregate 与 review

`learning_summary.json` 保存覆盖范围、源文件 SHA-256、采集错误、每主题事件数、页面数、
证据 ID 和页面信息。页面身份按原 URL（去除 fragment）的摘要区分；不因移除查询参数而误合并不同视频。
报告展示 URL 时删除凭据、query 和 fragment；原始文件仍保留源 URL。

当前 `duration_basis=unavailable_history_only`；主题的 `activity_seconds`、
`learning_seconds` 均为 null。首次/末次访问只是时间点，不相减充当时长。
Markdown 日报展示主题事件分布、重点网页、证据和待确认的后续建议。

完整 `run` 同时生成 `edge_history_timeline.html`：一个自包含、无需服务器的离线网页。
可独立运行 `python "<skill-dir>/scripts/generate_timeline.py" --input PATH --output PATH`；
输入可为原始或已分类导出。数据中的页面身份仍按原 URL（去 fragment）和配置文件区分，不同查询参数的网页不合并。界面默认每个原网页/配置文件一行并显示实际网页标题；工具栏“网页 / 网站”切换可进入每站一行的概览，再按需展开同站点的网页。站点视图可汇总多个配置文件，仍保留每次访问的 profile 和 visit_id；详情列出各次访问的完整标题、脱敏链接、时间与证据。仅将已知图标目录中通过域名边界匹配的主域和子域合在一行；未知域名仅去掉 www，不能误合并后缀伪装域名。搜索先匹配原网页的标题、网址或站点名，再将匹配网页汇总站点行，不会把同站点的无关网页一并算进搜索结果。
独立脚本未指定输入时，仅在 `output/` 和它的直接有效日期子目录中查找上述原始/已分类导出，文件名限定为 `learning_classified.json`、`edge_history_today.json` 或 `edge_history_YYYY-MM-DD.json`。按带时区的 `end_time` 选最新，覆盖时间相同优先已分类文件；同类同时间再按修改时间决定。不会遍历任意嵌套目录或读取其他 JSON。命令行打印选定来源路径；候选覆盖元数据损坏时报告具体文件并保留已有网页，显式 `--input` 可绕过自动选择。
网页统计窗口固定为源文件日期的本地 [06:00, 24:00)，按导出中声明的本地偏移计算，不依赖查看者的系统时间或时区。访问次数、网站/网页数、搜索、排序、详情和首末跨度均先筛选该窗口；跨越 06:00 的网页使用窗口内第一次真实访问作为跨度起点，不画虚构的 06:00 访问。次日 00:00 不计入当前日期，末端刻度显示 24:00。窗口外原始事件仍在嵌入数据和另存网页中保留；仅凌晨有记录时显示窗口内为空。原始采集 JSON、分类和已有报告的覆盖范围与计数不因网页过滤而改写。
1× 的时间画布适配可视宽度，在手机上也完整展示当天 06:00–24:00，不依赖固定最小 900px 横向画布。刻度密度随宽度变化，优先保留两端标签，字号不缩小。放大后按比例扩展画布并允许横向滚动；适配与缩放都不能改变访问次数、真实时间坐标或首末跨度。
窗口宽度改变后，放大视图按此前中心时间恢复，在浏览器实际可滚动范围内截取；边界使用上次稳定布局的位置，避免浏览器在重绘前夹限旧像素偏移而丢失阅读时间。保持倍率和有效的纵向位置，聚焦的访问与站点按钮按原事件 ID 或行标识恢复；详情保留自己的焦点，关闭时返回重绘后的原按钮。默认 1× 继续适配完整窗口。
画布以低对比斜纹标出 06:00–24:00 内但不在导出 `start_time/end_time` 覆盖范围内的时段，并按需显示“未覆盖”图例。边界使用声明时间，不使用首末访问、筛选结果或当前时间；完整日导出末端小于一个像素的差不画底纹。它不代表空闲或没有浏览，也不推定范围内每个配置文件均读取成功；部分失败仍按原状态提示。等待导入的模板不画底纹，真正零事件的导出仍保留声明的覆盖范围。
放大并平移后搜索，若首行结果没有可见访问点，则平移到最近的真实访问，不更改缩放或时间窗，也不抢走输入焦点。清空查询后恢复原来的时间中心和垂直位置；期间调节倍率仍保留新倍率，按原时间坐标而不是旧像素恢复。导入其他日期会清除旧的搜索位置。
输入法组合输入期间保留已有搜索结果，确认候选后才按最终文字过滤；取消组合输入不改查询，期间 Esc 不由网页清空搜索。提交后的相同查询不重复重绘；普通输入和既有定位恢复行为保持一致。
搜索以空白字符分隔多个关键词，忽略大小写及词序；同一原网页的站点名、标题、网址、域名及窗口内历次标题须共同包含所有关键词。先匹配原网页，再汇总站点，不能在同站点的不同网页之间拼凑命中；单词仍按子串匹配，不增加模糊推断或查询语法。
搜索命中词在访问预览、详情标题、网页分组标题和脱敏链接中以浅暖色 mark 强调，仅改变显示；原文字、事件身份和链接地址不变，主画布站名仍保持简洁。关键词作为字面文字匹配，正则特殊字符需转义；使用文字节点构造强调内容，不解析标题或查询中的 HTML。清空查询后重新展示内容须移除旧强调。
嵌入网页的地址会移除凭据、查询参数和 fragment，不包含外部脚本、字体、统计或 favicon 请求。
每次访问画为菱形；仅在两次以上且时间不同的访问之间绘制浅色虚线边框横条，明确称“访问跨度”。横条左右端和每个菱形均使用真实时间坐标，不设装饰性最小跨度。站点图标位于横条左侧并与其垂直居中，上方仅显示简短站点名（如 arXiv、GitHub），不附网页标题或功能描述，不显示域名、次数或首末时间文字；左侧留足图标空间，不移动或遮挡真实访问标记，无固定网页列；竖向参考线标记当前筛选的末次真实访问，不将历史数据误标为当前时间。
网页内始终显示标题/网址/域名搜索框，支持 `/`、Ctrl/Cmd+K 聚焦和 Esc 清空；不设主题或网站筛选。可离线导入其他单日 JSON，缩放固定 06:00–24:00 时间轴、查看证据并保存为新的独立 HTML。网站/网页分组、排序、配置文件和跨度开关位于“显示”菜单；单配置文件时隐藏配置文件选项。
访问点悬浮或聚焦时显示本地标题与秒级时间；近邻预览按当前缩放下 12px 距离选取实际事件，不代表一段持续活动，也不合并或删除事件。每个事件仍可用左右方向键、Home/End 精确选中并打开证据详情。缩放保持视口中心或滚轮指针下的时间，不能移动原始菱形以适配视觉。横向滚动时只将名称约束在视口内，图标、跨度和事件仍按时间坐标定位。上午/下午/晚上仅是时间刻度层级，不是浏览分类。
PageAgo 界面沿用用户主页的暖纸色、墨色文字与衬线品牌字；由 `assets/timeline_theme.css` 与 HTML 模板共同定义，构建后内嵌，不请求远程资源。页面只保留紧凑顶部和主时间画布，去除侧栏、主题筛选、小时柱图、大标题和装饰文案。主题标签保留在导出数据与报告，不参与网页筛选；横条颜色按域名稳定分配。
图标单独内嵌在 `site-icons` JSON 块中，只使用打包的官方 PNG/ICO 等光栅资源；原始导出或导入数据不能指定远程图片。主域名图标可用于真实子域名，不能匹配后缀伪装域名。
模板含内嵌预览样式与有效的 `dataset_kind: preview` JSON；直接打开会显示等待导入状态，导入后可另存为独立 HTML。
构建时替换完整的主题与数据块，成品不含待替换的数据或样式占位符。根目录 `index.html` 仅包含合成演示数据。
输入的 `dataset_kind: demo` 会保留到网页及另存的 HTML，并显式展示“示例数据”；未标记的输入默认为个人数据。
站点详情默认提供“网页”页签：每个原网页/配置文件一组，默认折叠重复访问，展开可查看其时间与事件证据；“访问”页签保留完整时间顺序。菱形点击直接打开访问页签并定位选中事件。网页分组使用当前筛选后的源页面，不能按标题或已脱敏链接合并，不包含窗口外或不匹配搜索的事件。隐藏页签与折叠内容中的链接不能进入对话框的焦点循环。
折叠网页卡片显示“首次 HH:mm · N 次访问”，时间取当前窗口内第一个真实事件，按导出时区显示，datetime 保留原偏移与秒级精度。站点清单包含多个 profile 时保留每卡片的 profile；只有一个时由详情头部说明，不逐项重复。profile 与原始 page_key 始终参与页面身份，展开证据不受辅助文字的省略影响。
独立 `review` 只有在输出目录存在与汇总的时间范围、总数和来源完全匹配的已分类记录时才补建时间轴，避免误配旧数据。

将来接入插件应新增独立的数据适配器，并明确记录前台、窗口焦点、空闲状态与活动区间；
在定义并校验该输入之前，本版不会把导入字段当作有效活动时长。
