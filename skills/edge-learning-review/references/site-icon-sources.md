## Official homepage declaration audit

On 2026-11-01, the arXiv homepage declared `/static/browse/0.3.4/images/icons/favicon-32x32.png` as its 32px favicon. Its root `/favicon.ico` is a different mascot, so the catalog now uses the declared red arXiv mark. Future refreshes prefer homepage-declared PNG favicons over guessed root paths.

ChatGPT and YouTube were visually checked against their homepage-declared PNG icons: the catalog icons show the same OpenAI knot and YouTube play-button identities. Bilibili's catalog favicon is byte-for-byte identical to the icon declared by its homepage at `https://i0.hdslb.com/bfs/static/jinkela/long/images/favicon.ico`. These matching catalog icons were retained.
